## 7. Cómo usar cada tipo de recurso

| Necesidad | Recurso correcto |
|---|---|
| "¿Qué hace exactamente esta casilla?" | Documentación oficial |
| "¿Cómo se ve el flujo completo?" | eLearning / video oficial |
| "¿Esta versión realmente hace esto?" | Tu propia base de datos (siempre gana) |
| "¿Alguien más tuvo este error?" | Foro oficial |
| "¿Existe ya un módulo para esto?" | Apps Store / OCA |
| "¿Cómo lo hace un consultor experimentado?" | Foro + sesiones de Odoo Experience en YouTube |
